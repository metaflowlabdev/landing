Что такое Explorer

Explorer — нативный файловый менеджер для macOS, который переносит привычки Windows 11 File Explorer на Mac: вкладки, адресная строка с хлебными крошками, восемь режимов вида и горячие клавиши Ctrl-слоя.

Если вы пришли с Windows, Explorer даёт знакомую модель работы: «Этот компьютер» с томами, «Быстрый доступ», закреплённые папки, контекстное меню с привычными пунктами. При этом всё работает по-маковски — горячие клавиши ⌘ тоже действуют, а файлы лежат там же, где их видит Finder.

Это alpha-версия (v0.1.0). Базовая навигация, операции с файлами, поиск и свойства уже работают. Часть фич Windows 11 ещё в разработке — они собраны в разделе 🚧 Скоро и явно помечены по тексту.

Что уже умеет Explorer

  • Вкладки как в браузере + несколько независимых окон;
  • Навигация: назад/вперёд/вверх, адресная строка с крошками и автодополнением;
  • Боковая панель в стиле Windows: Главная, iCloud Drive, Этот компьютер, Быстрый доступ;
  • 8 режимов вида с миниатюрами QuickLook;
  • Копировать/вырезать/вставить, переименование (в т.ч. массовое), создание, удаление, отмена/повтор;
  • Сжатие и извлечение ZIP;
  • Поиск по папке и подпапкам с синтаксисом kind: ext: size: date:;
  • Окно «Свойства» с вкладками Общие / Подробности / Безопасность.
Главное окно Explorer: вкладки, тулбар с адресной строкой, боковая панель, список файлов и статус-бар.

Установка и первый запуск

Explorer распространяется как обычное приложение macOS. Первый запуск требует пройти проверку Gatekeeper и — для полноценной работы — выдать доступ к диску.

Установка

  1. Откройте загруженный образ .dmg и перетащите Explorer в папку «Программы» (Applications).
  2. Извлеките образ и запустите Explorer из «Программ» (а не из образа) — так все обновления встанут корректно.

Gatekeeper при первом запуске

macOS защищает систему от запуска неизвестных программ. При первом открытии может появиться предупреждение.

  1. Если macOS говорит, что приложение «не удаётся открыть» — нажмите OK (не «В корзину»).
  2. Откройте Системные настройки → Конфиденциальность и безопасность.
  3. Внизу найдите строку про Explorer и нажмите «Открыть всё равно».
  4. Подтвердите паролем или Touch ID. Дальше Explorer запускается обычным двойным кликом.
Диалог Gatekeeper. Нажмите OK, затем разрешите запуск в Системных настройках.

Доступ к диску (Full Disk Access)

Чтобы Explorer видел все папки — включая системные расположения и тома — выдайте ему полный доступ к диску.

  1. Откройте Системные настройки → Конфиденциальность и безопасность → Полный доступ к диску.
  2. Включите переключатель напротив Explorer (если его нет в списке — добавьте кнопкой «+»).
  3. Перезапустите Explorer, чтобы доступ вступил в силу.

Без полного доступа к диску Explorer работает, но некоторые защищённые папки могут показываться пустыми или с предупреждением «нет доступа». Подробнее — в разделе Разрешения и приватность.

Окно с одного взгляда

Окно Explorer состоит из пяти зон. Разберём каждую — дальше в документации мы будем ссылаться именно на эти названия.

1 Полоса вкладок

Сверху — вкладки как в браузере: каждая держит свою папку и свою историю переходов. Кнопка «+» открывает новую, крестик закрывает. Подробнее: Вкладки.

2 Тулбар: навигация + адресная строка + поиск

Кнопки Назад / Вперёд / Вверх / Обновить, адресная строка с хлебными крошками и поле поиска. См. Навигация и Адресная строка.

3 Боковая панель

Дерево узлов: Главная, iCloud Drive, Быстрый доступ, Этот компьютер. Сворачивается по ⌘B. См. Боковая панель.

4 Список файлов

Главная область. Двойной клик по папке открывает её, по файлу — запускает приложение по умолчанию. Вид настраивается восемью режимами (Режимы вида).

5 Статус-бар

Внизу — счётчик: всего элементов в папке и сколько выделено (с суммарным размером выделенного).

Вкладки

Вкладки работают как в браузере: каждая хранит свою папку и свою историю «назад/вперёд». Можно держать рядом несколько мест и быстро переключаться.

Открыть, закрыть, переключить

  • Открыть: ⌘T или кнопка «+» на полосе вкладок.
  • Закрыть: ⌘W, крестик на вкладке или средняя кнопка мыши по вкладке. Когда закрывается последняя вкладка окна — закрывается само окно.
  • Переключить по порядку: Ctrl+Tab (следующая), Ctrl+Shift+Tab (предыдущая).
  • Перейти к номеру: ⌘1…⌘9 — к вкладке с этим порядковым номером.
Полоса вкладок: «+» для новой, крестик для закрытия, кнопка ⌄ справа — список всех вкладок.

Переупорядочить и перетащить

  • Перетащите вкладку влево/вправо, чтобы изменить порядок.
  • Вытащите вкладку за пределы полосы — она откроется в новом окне. То же делает пункт меню вкладки «Переместить в новое окно».
  • Вкладку можно перетащить и в другое уже открытое окно.

Контекстное меню вкладки

Правый клик по вкладке: Дублировать, Закрыть остальные, Закрыть справа, Переместить в новое окно.

Список всех вкладок

Кнопка-дропдаун справа на полосе (как в Chrome) показывает список всех открытых вкладок с поиском по ним — удобно, когда вкладок много и заголовки усечены.

Уплотнение

Чем больше вкладок, тем уже каждая: имя усекается с хвоста, на узких прячется крестик, при переполнении появляется горизонтальный скролл. Полоса вкладок не «толкает» боковую панель — ужимается в своей зоне.

Открыть папку в новой вкладке

Пункт «Открыть в новой вкладке» есть в контекстном меню папки — в боковой панели, в списке файлов и на плитках Главной.

Восстановление при перезапуске

Если включена настройка «Восстанавливать вкладки» (по умолчанию включена), при следующем запуске Explorer вернёт открытые вкладки.

Восстановление пока работает для одного окна. Возврат раскладки нескольких окон — 🚧 в разработке.

Назад / Вперёд / Вверх / Обновить

Четыре кнопки навигации в тулбаре повторяют логику Windows 11 — у каждой вкладки своя независимая история.

ДействиеКнопка / клавишаЧто делает
Назад⌘[ · BackspaceВ предыдущую папку из истории вкладки.
Вперёд⌘]Вперёд по истории (после «Назад»).
Вверх⌘↑На один уровень выше — в родительскую папку.
Обновить⌘R · F5Перечитать содержимое текущей папки.

История кнопок

Долгое нажатие / правый клик по кнопке Назад или Вперёд открывает список истории — можно прыгнуть на несколько шагов сразу.

Авто-обновление

Explorer следит за изменениями файловой системы (FSEvents): если файлы в открытой папке создаются, удаляются или переименовываются вне Explorer — список обновится сам, вручную жать «Обновить» не нужно.

Адресная строка и хлебные крошки

Адресная строка показывает путь как цепочку кликабельных сегментов — и превращается в редактируемое поле, если кликнуть в пустое место.

Каждый сегмент кликабелен; стрелка ▾ у сегмента раскрывает соседние папки того же уровня.

Хлебные крошки

  • Клик по сегменту — перейти в эту папку.
  • Стрелка ▾ у сегмента — выпадашка с соседними (sibling) папками того же уровня для быстрого бокового перехода.

Редактируемый путь

  1. Кликните в пустое место строки (или нажмите ⌘L) — крошки превратятся в текстовое поле.
  2. Введите путь: поддерживаются ~ (домашняя папка) и абсолютные пути; работает автодополнение.
  3. Нажмите Enter — переход в указанную папку.

⌘L мгновенно ставит фокус в адресную строку. Есть и история введённых адресов — выпадающий список под полем.

Копировать путь

Скопировать путь текущей папки можно из меню File или сочетанием Ctrl/⌘+Shift+C для выделенных элементов (см. Буфер обмена).

Боковая панель

Навигационная панель слева повторяет дерево Windows 11: Главная, облако, Быстрый доступ, Этот компьютер с томами.

Группы

УзелЧто внутри
ГлавнаяБыстрый доступ, Избранное, Недавние (см. Главная).
ГалереяУзел есть; наполнение лентой фото — 🚧 скоро.
iCloud DriveНа месте OneDrive из Windows. Значки статуса синхронизации — 🚧 скоро.
Быстрый доступЗакреплённые папки + часто используемые.
Этот компьютерТома с полосой заполнения и стандартные папки профиля.
СетьУзел есть; обзор SMB — 🚧 скоро.
КорзинаУзел есть; просмотр содержимого корзины — 🚧 скоро.

Дерево и раскрытие

  • Треугольники разворачивают узлы; при навигации дерево авто-раскрывается до текущей папки.
  • Группы сворачиваются и запоминают своё состояние между запусками. «Этот компьютер» раскрывается стрелкой самой строки.

Закрепление

Закрепить или открепить папку в Быстром доступе — из контекстного меню (в списке файлов или в самой панели). Закрепление перетаскиванием появится вместе с расширением drag&drop.

Размер и видимость

  • Ресайз: потяните границу панели.
  • Скрыть/показать: ⌘B, кнопка в тулбаре или меню Вид → Боковая панель. Состояние запоминается.

Режимы вида

Explorer поддерживает все 8 режимов отображения Windows 11 — от огромных значков до детальной таблицы. Каждому соответствует своя цифра Ctrl+Shift+1…8.

ЦифраРежимХоткей
1Огромные значкиCtrl+Shift+1
2Крупные значкиCtrl+Shift+2
3Обычные значкиCtrl+Shift+3
4Мелкие значкиCtrl+Shift+4
5СписокCtrl+Shift+5
6Таблица (детальный список)Ctrl+Shift+6
7ПлиткаCtrl+Shift+7
8СодержимоеCtrl+Shift+8

По умолчанию — Таблица. Выбранный режим запоминается между запусками.

Переключение колесом

Зажмите Ctrl (или ⌘) и крутите колесо мыши: вверх — к более крупному виду, вниз — к мельче. Перебор идёт по порядку 1→8 без заворота (упёрлись в край — дальше не идёт). Работает и в таблице, и в значковых режимах.

Слева — значковый режим, справа — детальная Таблица с колонками.

Компактный интервал

Вид → Компактный интервал уменьшает высоту строк детального списка (24 → 18 px) — на экран влезает больше файлов. Настройка запоминается.

Колонки таблицы можно ресайзить и переставлять, раскладка сохраняется между запусками. Настраиваемый набор колонок, фильтр-чекбоксы в заголовке и группировка — 🚧 в разработке.

Миниатюры и значки

В крупных режимах Explorer показывает настоящие превью содержимого через QuickLook — для изображений, видео и PDF.

Где появляются миниатюры

  • Реальные QuickLook-превью — в крупных значковых режимах (огромные / крупные / обычные / плитка / содержимое, размер значка ≥ 32pt).
  • В мелких значках и списке показываются системные иконки типа файла.

Как это работает

  • Превью генерируются лениво — только для видимых ячеек, с учётом Retina-чёткости.
  • Готовые миниатюры кешируются в памяти (лимит ~64 МБ), при прокрутке не пересоздаются.
  • Для огромных папок генерация не тормозит прокрутку: за пределами экрана задачи отменяются.

Значок-оверлей для ярлыков (стрелка на иконке) — 🚧 в разработке.

Сортировка

Файлы сортируются по имени, дате изменения, типу или размеру — по возрастанию или убыванию.

Как сортировать

  • Клик по заголовку колонки в режиме Таблица — сортировка по этой колонке; повторный клик меняет направление.
  • Контекстное меню фона папки → Сортировка — выбрать ключ (Имя / Дата изменения / Тип / Размер) и направление (По возрастанию / По убыванию). Галочка отмечает активные.

Заголовок колонки и меню сортировки синхронизированы — это один и тот же параметр.

Главная (Home)

Стартовый экран Explorer — как «Главная» в Windows 11: быстрый доступ к закреплённому, избранным файлам и недавним.

Разделы Главной

РазделЧто показывает
Быстрый доступЗакреплённые папки + часто используемые.
ИзбранноеЗакреплённые отдельные файлы.
НедавниеНедавно открывавшиеся файлы.
РекомендуемоеПодборка по локальной эвристике (без облака).

Каждый раздел сворачивается шевроном у заголовка, состояние запоминается между запусками.

Как закрепить

  • Папку → контекстное меню → «Закрепить в Быстром доступе».
  • Файл → контекстное меню → «Добавить в Избранное».

Выделение

Выделять файлы можно мышью и клавиатурой — поведение совпадает с Windows и Finder одновременно.

СпособРезультат
КликВыделить один элемент (заменить выделение).
⌘/Ctrl + кликДобавить/убрать элемент из выделения (toggle).
Shift + кликВыделить диапазон от предыдущего до текущего.
Рамка мышьюПротянуть прямоугольник по пустому месту — выделить всё внутри.
Type-aheadНачните набирать имя — фокус прыгнет к подходящему элементу.

Выделить всё / снять / инвертировать

  • Выбрать всё: Ctrl/⌘+A.
  • Снять выделение: Esc или меню «Снять выделение».
  • Инвертировать: ⇧⌘I — выделить всё, кроме текущего выделения.

Клавиатурная навигация по списку — стрелки, Home/End, PgUp/PgDn, Enter (открыть).

Копировать / Вырезать / Вставить

Буфер обмена работает как в Windows: вырезанные элементы становятся полупрозрачными до вставки, а конфликты имён решаются автоматически.

ДействиеКлавишиМеню
КопироватьCtrl/⌘+CКонтекстное меню элемента
ВырезатьCtrl/⌘+XКонтекстное меню элемента
ВставитьCtrl/⌘+VМеню элемента и фона папки
Копировать путьCtrl/⌘+Shift+CМеню элемента и File

Особенности

  • Вырезанные элементы показываются полупрозрачными (≈50%) до момента вставки.
  • Вставлять можно как в открытую папку, так и на пустое место (фон) папки.
  • При конфликте имени Explorer авто-переименовывает копию: «имя 2», «имя 3» — без диалога.

И Ctrl, и ⌘ работают для всех этих команд: ⌘ — родной для Mac, Ctrl — мускульная память из Windows.

Переименование

Переименовать файл можно клавишей F2 или медленным вторым кликом по имени. Несколько файлов сразу переименовываются в стиле Windows 11.

Один файл

  1. Выделите файл и нажмите F2 (или медленно кликните по имени второй раз).
  2. Имя становится редактируемым; выделяется без расширения — расширение не затрётся случайно.
  3. Введите новое имя и нажмите Enter.

Массовое переименование

Выделите 2 и более файлов, нажмите F2, введите общее базовое имя — Explorer присвоит:

отчёт (1).pdf
отчёт (2).docx
отчёт (3).png

Это Win11-формат: общий base + порядковый номер в скобках, у каждого файла своё расширение. Всё массовое переименование — одна операция отмены (Ctrl/⌘+Z вернёт все имена сразу).

Удаление

Файлы можно отправить в Корзину (обратимо) или удалить безвозвратно.

ДействиеКлавишиОбратимо?
В КорзинуDel · Fn+Delete · меню «Удалить»Да — можно отменить (Ctrl/⌘+Z) или восстановить из Корзины.
БезвозвратноShift+Del · меню «Удалить безвозвратно»Нет — мимо Корзины, в историю отмены не попадает.

Перетаскивание (Drag & Drop)

Файлы перемещаются перетаскиванием внутри окна Explorer — на папки в списке и на узлы боковой панели.

Что работает сейчас

  • Перемещение в папку: бросьте файлы на папку в списке — они переместятся внутрь.
  • На узел боковой панели: бросьте на папку-узел (у которого есть реальная папка) — переместятся туда.
  • Копирование вместо перемещения: зажмите Option при сбросе — Explorer скопирует, а не переместит.
  • Защита от ошибок: нельзя бросить папку в саму себя, в свою же вложенную папку или на не-папку — такая цель подсветится как недопустимая.

🚧 В разработке: перетаскивание между вкладками и окнами, в Finder и из него, создание alias перетаскиванием, spring-loaded раскрытие папок при наведении.

Архивы ZIP

Explorer умеет сжимать выделенное в ZIP и извлекать ZIP-архивы прямо из контекстного меню.

Сжать в ZIP

Выделите один или несколько объектов → контекстное меню → «Сжать в ZIP». Архив создаётся в текущей папке:

Что выделеноИмя архива
Один файл<имя>.zip (файл в корне архива)
Одна папка<имя>.zip (со структурой папки)
Несколько объектовАрхив.zip (со структурой)

При совпадении имени — авто-уникализация: note.zip → note 2.zip. Создание архива отменяется Ctrl/⌘+Z.

Извлечь всё…

Выделите ровно один .zip → контекстное меню → «Извлечь всё…». Содержимое распаковывается в подпапку рядом с архивом с именем архива (data.zip → папка data, при конфликте — data 2). Отмена удаляет распакованную подпапку.

🚧 В разработке: вход в ZIP как в папку без распаковки; форматы 7z, TAR, RAR; мастер сжатия с настройками.

Контекстные меню

Правый клик даёт два разных меню: по элементу (файлу/папке) и по пустому фону папки. Пункты появляются по контексту — то, что нельзя сделать, не показывается.

Слева — меню элемента, справа — меню пустого фона папки.

Меню элемента (файла / папки)

  • Открыть; для папки — «Открыть в новой вкладке»; для файла — подменю «Открыть с помощью» (список приложений-кандидатов, дефолт помечен, + «Выбрать программу…»).
  • Закрепить/открепить папку в Быстром доступе; Добавить/удалить файл в Избранное.
  • Копировать · Вырезать · Вставить · Копировать путь.
  • Поделиться… — системный share-лист (AirDrop, Почта, Сообщения…).
  • Переименовать · Создать ярлык · Сжать в ZIP · Извлечь всё… (последний — только для одиночного .zip).
  • Удалить · Удалить безвозвратно · Свойства.

Действия для изображений

Если выделены изображения, в меню появляются: Сделать фоном рабочего стола, Повернуть вправо, Повернуть влево.

Меню фона папки

  • Вид ▸ — подменю с 8 режимами (галочка у активного);
  • Сортировка ▸ — ключ и направление;
  • Создать ▸ — Папку / Текстовый документ;
  • Вставить (если в буфере что-то есть);
  • Открыть в Терминале — Terminal.app в текущей папке;
  • Свойства текущей папки.

Свойства

Окно «Свойства» открывается по Alt+Enter (Option+Enter) или из контекстного меню «Свойства». Содержимое зависит от того, что выделено.

Файл — вкладка «Общие»

Тип, размер, расположение, даты создания и изменения, атрибуты (скрытый / только чтение). Read-only.

Вкладка «Подробности»

Список «ключ: значение»: имя, полный путь, идентификатор типа (UTI), даты добавления/создания/изменения, размер, для изображений — размеры в пикселях.

Папка

Размер считается рекурсивно в фоне (не блокирует окно): «Вычисление…» → итог. Плюс «Содержит: файлов N, папок M».

Том

Для корня тома — кольцевая диаграмма заполнения, занято/свободно/всего и имя тома.

Несколько объектов

При выделении 2+ — сводка: «Выделено: N элементов», суммарный размер (рекурсивно для папок), «Содержит: файлов/папок».

Вкладка «Безопасность»

Права POSIX в режиме чтения: владелец/группа/остальные (r/w/x), строка вида rwxr-xr-x и octal 755.

🚧 В разработке: редактирование тегов/рейтинга, расширенные EXIF/кодеки, ACL и изменение прав, переименование тома.

Поиск и фильтры

Поле поиска в тулбаре ищет в текущей папке и всех подпапках, выдавая результаты по мере обхода — без зависания интерфейса.

Как искать

  1. Кликните в поле поиска (справа в тулбаре) и начните печатать.
  2. Результаты появляются инкрементально (порциями) во время поиска.
  3. В колонке «Папка» виден относительный путь найденного от исходной папки.
  4. Пункт «Открыть расположение файла» переводит в папку, где лежит результат.

Поиск идёт без индекса — прямым рекурсивным обходом в фоне. Симлинк-петли и недоступные папки пропускаются, лимит результатов — 5000.

Кнопка-фильтр

Поповер фильтра рядом с полем: выбор типа (Изображения / Видео / Аудио / Документы / Папки / Архивы) добавляет токен kind: в запрос, плюс список недавних поисков.

История поиска

Последние запросы (до 20, без дублей) хранятся и доступны в выпадашке фильтра.

🚧 В разработке: подсветка совпадений в имени, сохранённые поиски, поля даты/размера прямо в поповере.

Назад← СвойстваДалееСинтаксис запроса →

Синтаксис запроса

В поле поиска можно смешивать обычные слова с фильтрами вида ключ:значение. Нераспознанные токены просто становятся текстом для поиска. Ключевые слова понимают и русские, и английские синонимы.

Фильтры

ФильтрЧто задаётПримеры
kind:Тип объектаkind:image, kind:видео, kind:документ, kind:папка, kind:архив
ext:Расширение файлаext:pdf, ext:png
size:Размер (бинарные КБ/МБ/ГБ)size:>1MB, size:<=100KB, size:1MB..5MB, size:1мб
date:Дата изменения «не раньше»date:today, date:вчера, date:week, date:месяц, date:year

Типы для kind:

image (изображение/фото/картинка) · video (видео) · audio (аудио/музыка/звук) · document (документ/doc) · folder (папка/каталог/dir) · archive (архив).

Маски

Символ * допускается (например, в ext: он отбрасывается при нормализации). Свободный текст матчится по имени.

Размеры

Единицы: B/Б, KB/КБ, MB/МБ, GB/ГБ (степени 1024). Операторы: >, >=, <, <= и диапазон a..b.

Пример: kind:image size:>500KB date:week отпуск — изображения больше 500 КБ, изменённые за последнюю неделю, с «отпуск» в имени.

Разрешения и приватность

Explorer работает с локальными файлами. Ниже — что и зачем он запрашивает, и что он точно НЕ делает.

Что может запрашиваться

РазрешениеЗачем
Полный доступ к диску (Full Disk Access)Чтобы видеть и открывать все папки, включая защищённые системные расположения. Без него часть папок может быть недоступна.
Доступ к папкам (Документы, Рабочий стол, Загрузки)macOS может разово спросить разрешение при первом обращении к этим папкам — это штатное поведение системы.

Что Explorer НЕ делает

  • Не использует Spotlight-индекс — поиск идёт собственным обходом папок, без обращения к системному индексу.
  • Не отправляет содержимое файлов наружу — все операции локальны.
  • Не требует доступа к Фото, Контактам, микрофону или камере для базовой работы.

Выдать или отозвать доступ можно в любой момент: Системные настройки → Конфиденциальность и безопасность → Полный доступ к диску.

🚧 Скоро

Эти возможности Windows 11 ещё не реализованы в alpha-версии. Список отражает план развития — пункты могут меняться.

Операции с файлами

  • Единое окно прогресса операций: список задач, скорость, оставшееся время, пауза/возобновление/отмена;
  • Диалог конфликтов: Заменить / Пропустить / Сравнить, «для всех конфликтов»;
  • Drag & drop между вкладками, окнами и в/из Finder; alias перетаскиванием; spring-loaded папки.

Вид и колонки

  • Настраиваемый набор колонок таблицы, автоподбор ширины;
  • Фильтр-чекбоксы в заголовке колонки, группировка по свойствам;
  • Запоминание вида per-folder и шаблоны типов папок;
  • Панель предпросмотра (Alt+P) и панель деталей;
  • Плавный слайдер размера значка внутри режима; оверлей-стрелка ярлыка.

Корзина, архивы, диски, сеть

  • Полноценный узел Корзины: просмотр, восстановление, очистка;

  • Извлечение съёмных томов (eject); обзор сети SMB, подключение сетевого диска.

Галерея, облако, прочее

  • Галерея фото по датам; статусы синхронизации iCloud значками;
  • Полноценное окно «Параметры»;
  • Диалоги подтверждения, расширенные свойства (теги, EXIF, редактирование прав);
  • Сохранённые поиски, подсветка совпадений; поля даты/размера в фильтре поиска;
  • Восстановление раскладки нескольких окон при перезапуске.
