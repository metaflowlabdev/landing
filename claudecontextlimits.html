Four numbers, the whole picture

Everything you need to know about your Claude Code limits, at a glance.

The 5-hour and weekly windows, side by side

Claude Code limits you on two clocks — a rolling 5-hour budget and a weekly one. ClaudeContextLimits shows both: top line is the 5-hour window, bottom line is the week. Each reads percent used and time to reset (m minutes, h hours, d days).

Two sources: exact or fully offline

Server pulls the real numbers the same way Claude Code does — /api/oauth/usage, using the token already in your Keychain — so they match /usage to the digit. Logs estimates locally from ~/.claude/projects, with no network and no token at all. Switch anytime from the menu.

Colour-coded, or quietly monochrome

In Colour mode each line is tinted by how close you are to the cap — blue under 50%, yellow at 50, orange at 75, red at 90 — exactly like Claude's own warning steps. Prefer it subtle? Mono mode renders as a normal template glyph that adapts to your menu-bar colour.

One click from the menu bar

Click the numbers for a tidy menu: refresh on demand, flip the data source, switch Mono ↔ Colour, or quit. Your choices stick between launches. No windows, no Dock icon — it just sits up top and stays out of the way.

Under the hood

No scraping, no middle-man server — it talks to the same endpoint Claude Code does.

Exactly like /usage

Server mode reads your OAuth token from the Keychain entry Claude Code-credentials and calls /api/oauth/usage directly. Same request, same answer — the figures line up with /usage. Polled every 5 minutes, because Anthropic throttles frequent calls.

Offline estimate from logs

Logs mode sums the token counts in your local ~/.claude/projects/**/*.jsonl over the last 5 hours and 7 days — no network, no token. It's an estimate against your plan's ceiling, refreshed every 30 seconds.

Private by default

No account, no analytics, nothing leaves your Mac except the one request to Anthropic's own API in Server mode — the very same call Claude Code makes. Logs mode never touches the network at all.

Tiny & native

One Swift file, plain AppKit, no dependencies. It runs as a menu-bar agent (LSUIElement) — no Dock icon, no window — and sips almost no resources while it keeps your numbers fresh.
